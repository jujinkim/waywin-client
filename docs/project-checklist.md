# 채택한 프로젝트 기준

체크는 **기준 채택**을 뜻한다. 실제 통과·실패·미실행은 `task.md`와 검증 결과에 따로 기록한다. 변경 전 관련 기준을 읽고 변경 후 해당 결과와 대조한다.

- [x] **안정성 우선:** 모든 런타임 기능에 장시간·반복·장애 격리 기준을 적용한다. 8시간/5앱, 20회 재연결, 프로세스 정지·종료로 검증한다.
- [x] **Linux 데스크톱 지원:** 사용자 변경에 따라 GNOME·KDE 등의 Wayland와 X11을 함께 대상으로 한다. 실제 SDL 드라이버, 데스크톱·컴포지터와 실기기·VM·WSLg를 기록하며 각 환경의 결과를 구분한다. macOS·교차 컴파일은 실환경 증거가 아니다.
- [x] **GUI 완결성:** 제품의 모든 기능에 GUI 진입점·오류·복구를 제공한다. 트레이가 없는 환경과 연결 중 취소·호스트 선택을 확인한다. 0단계 개발 도구는 제품 GUI가 아니다.
- [x] **호스트 구분:** 목록·원격 창에 이름과 색상을 함께 제공한다. 두 호스트 동시 조작 시 대상 ID·세션 세대·입력·클립보드를 확인한다.
- [x] **비밀정보 보호:** 선택 저장은 키링에만 한다. 인자·설정·로그에 비밀번호를 넣지 않는다. 시험 도구도 비밀번호 인자를 받지 않는다. 키링 실패·인증서 변경·출력 유출을 검사한다.
- [x] **요구사항 보존:** R1–R7을 유지한다. 2026-11-14 사용자 요청에 따라 제품 구현과 실환경 검증을 병행한다. 구현 및 모의 테스트를 실환경 통과로 기록하거나 몇 개 앱의 성공을 모든 창 지원으로 기록하지 않는다. 미검증/실패와 대안을 명시한다.
- [x] **의존성 통제:** FreeRDP 3.33.1 소스를 커밋으로 고정한다. 수정 패치·빌드 옵션·시스템 의존성·라이선스와 복원 방법을 추적한다. 버전 문자열만으로 출처를 증명하지 않는다.
- [x] **변경 전후 검증:** 단위·계약·장애 주입 테스트 우선. 실제 GUI 검증과 모의 테스트를 구분한다. 컴퓨터 사용은 목적·종료 조건을 사전 정의한다.
- [x] **작업 단위 저장:** 관련 검사 후 변경과 `task.md`를 자동 로컬 커밋한다. 무관한 파일·비밀·실환경 원본 로그는 제외하고 원격 작업 권한을 별도로 확인한다.
- [x] **수명과 경계:** GUI 네트워크/영상 처리 금지, 호스트별 세션 프로세스, 버전·지원 기능 협상, 오래된 이벤트 폐기를 계약/장애 테스트로 검증한다.
- [x] **데이터 최소화:** 추가 수신 포트·분석·화면 녹화·키 입력 수집 없음. 시험 이벤트는 고정된 종류·숫자 ID만 기록하며 창 제목·입력 내용·아이콘 내용은 기록에 수집하지 않는다. 제품 표시·입력에는 메모리의 일시적 메시지만 사용한다.
- [x] **원본 셸 UI:** 작업표시줄 전체 대신 시작 메뉴·IME 설정·빠른 설정의 개별 미러링을 허용한다. P09에서 실제 원격 표시·조작·동일 세션을 각각 확인한다. 단순 실행/URI 호출 성공을 합격으로 기록하지 않는다.
- [x] **멀티모니터 정합성:** 호스트 물리 화면·클라이언트 화면·RDP 세션 화면을 분리한다. P10/M01–M06으로 1↔다중 조합, 선택 주 모니터, 음수 좌표, 회전, 혼합 배율, hotplug/재접속 후 창 회수·입력을 검증한다. 정적 레이아웃 지원을 동적 변경 지원으로 확대 해석하지 않는다.
